# aprendizaje-supervisado-titanic

## Panel de resultados

Abre `index.html` en cualquier navegador para consultar los resultados de
Random Forest y Regresión logística. Es una página independiente: no necesita
iniciar Flask ni instalar dependencias adicionales.

Las métricas mostradas corresponden a la evaluación de los modelos sobre la
partición estratificada de prueba (20 %, `random_state=42`) del notebook
`4_5_train.ipynb`.
